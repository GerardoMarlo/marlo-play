## Inspección visual

Se revisaron las 40 ilustraciones de la fuente mediante una hoja de contacto. La selección incluye animales con regalos, marcos navideños y rótulos originales de las cartas. Las cartas se muestran completas para preservar ilustración, título y símbolos.

**Excluida:** `Carbón Para Ti Christmas Gifts.png` contiene la marca anterior “CARBÓN PARA TI”. No se copia a los recursos públicos ni se usa como portada. Ninguna de las ocho cartas seleccionadas muestra ese nombre anterior.

No se infieren reglas completas, componentes de caja, edades, duración o número de jugadores a partir de este arte. La carta “Yo quería ése” contiene texto de acción original; ello no sustituye un reglamento confirmado.

No hay fotografía de caja o mockup de empaque en esta selección. La composición de cartas es una presentación de ilustraciones auténticas, no una foto del producto físico.
