## Seguridad y exactitud

`POST /api/tracking` valida origen, Turnstile fuera del modo local, máximo de 8 consultas por minuto por IP y 120 globales. No consulta al proveedor para guías desconocidas o ambiguas. Caché/lease de cinco minutos por guía, reintentos acotados y limitador compartido de Skydropx (una solicitud cada 550 ms). Ante fallos se conserva el último estado confirmado y se informa que no se pudo actualizar.

La respuesta pública contiene únicamente guía, transportista, estado, última fecha informada e historial de estados/fechas. Excluye identificadores internos, nombres, direcciones, correo, teléfono, importes, pagos, etiquetas PDF, URLs externas y textos libres que pudieran contener datos personales. La página usa `no-store`, `noindex` y `no-referrer`.

El webhook existente verifica HMAC-SHA512 del cuerpo original y limita el tamaño a 64 KB. Extrae únicamente la referencia; los estados se consultan de nuevo mediante la API autenticada. Duplicados procesados se reconocen sin repetir consultas ni correos, los eventos desconocidos se ignoran, las respuestas antiguas no sobrescriben estados posteriores y se protegen estados terminales. El estado del pedido y los correos tienen guardas transaccionales adicionales para respuestas concurrentes.

No se inventan fechas de entrega: el contrato consultado no proporciona una fecha estimada fiable. Las fechas sin zona horaria se muestran sin asignarles una zona inventada. La recogida local no genera guías. El pedido privado explica cuándo llegará la guía o cómo coordinar la recogida.

## Verificación del proveedor

- [OpenAPI oficial consultado](https://pro.skydropx.com/es-MX/api-docs.json): GET `/api/v1/shipments/tracking` con `tracking_number` y `carrier_name`; HTTP 200 devuelve `data[]` con `attributes.status` y `attributes.date`; HTTP 404 indica ausencia de eventos. Los campos libres se descartan por privacidad.
- Consulta real de la guía sandbox ya existente: envío HTTP 200, transportista `fedex`, estado `created`; rastreo HTTP 404 sin eventos. Se comprobó autenticación y contrato de ausencia de movimientos. No se compraron guías ni se solicitaron recolecciones.
- Panel de producción verificado: webhook “MARLO GAMES STORE” activo, URL correcta y HMAC. Seleccionados Created, Exception, Picked_up, In_transit, Last_mile, Delivery_attempt, Delivered, Delivered_to_branch, In_return, Canceled y Error. No fue necesario cambiar ni duplicar la configuración.
- [Documentación oficial de webhooks](https://help.skydropx.com/articulos-cda/configuracion-de-webhooks).

## Pruebas y límites de aceptación

Suite completa: 116 pruebas en 16 archivos aprobadas. Después de reforzar la concurrencia de correos se repitieron las 18 pruebas de rastreo/fulfillment, aprobadas; TypeScript y compilación Vite correctos. Pruebas de navegador a 1440, 1280, 768 y 390 px: rutas, precarga, historial, errores, FAQ y enlaces, controles circulares, recogida sin CP, envío con cobertura y ausencia de desbordamiento. Las pruebas visuales de historial usan respuestas controladas, identificadas como vista local.

Producción comprobada después de publicar: ambas páginas legales HTTP 200; rastreo visible, guía precargada, protección anti-bot, FAQ con $0/$70 y enlace funcional; recogida sin CP y total nacional $329 para un juego de $259. No se enviaron pedidos. Webhook: firma falsa HTTP 401; firma válida para referencia inexistente HTTP 200 `ignored`. Captura pública: `docs/ux-verification/published-tracking-390.png`.

La cuenta de pruebas todavía no dispone de eventos reales de tránsito/entrega para esa guía: el HTTP 200 con historial y el ciclo de entrega auténtico se validaron con contratos controlados, no con un paquete que haya recorrido la paquetería. Falta esa aceptación operativa con un envío real; no faltan nuevos secretos ni suscripciones para esta implementación.

Los pagos reales y la compra de guías permanecen desactivados. La vista local en `http://127.0.0.1:5173` permite crear pedidos y simular pagos sin cobros, correos ni envíos. No constituye una tienda sandbox pública conectada de extremo a extremo a los proveedores.
