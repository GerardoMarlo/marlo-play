# Marlo Games: implementación local

El portal personal ya vive en my.marlo.games. El gateway existente y sus
configuraciones permanecen fuera de esta aplicación. No publicar esta tienda
ni asociar marlo.games sin autorización expresa.

1. Base React/TypeScript/Vite/Tailwind, diseño editorial y contenido editable.
2. Dominio comercial: catálogo, carrito, cupones, direcciones y cotizaciones.
3. API Worker + D1, reservas atómicas, estados de pedido, outbox e integraciones.
4. Administración protegida, contenido, inventario, logística y auditoría.
5. Pruebas locales, compilación, revisión visual y documentación de activación.

Pendientes del propietario: catálogo, SKU, precio, stock, peso y dimensiones;
fotografías y banners; contactos y redes; políticas revisadas; domicilio de
origen logístico; cuentas sandbox y secretos de los cuatro proveedores;
dominio verificado de correo; configuración de Cloudflare Access para admin.
La ausencia de estos recursos no habilita datos ficticios en producción.
